# 归档：状态机架构版本

**归档日期**: 2026-04-30

## 概述

这是第一次尝试重构为状态机架构的版本。因需求不明确而归档。

## 状态定义

| 状态 | 颜色 | 含义 |
|-----|------|------|
| `offline` | 🔴 红 | 服务未启动 |
| `started` | 🟠 橙 | 服务已启动，未连接 |
| `connecting` | 🔵 蓝 | 连接中 |
| `recording` | 🟢 绿 | 转录中 |

## 状态转换

```
点击
  │
  ▼
┌──────────────────────────────────────────────────┐
│  offline → started → connecting → recording       │
│      ↑                              │            │
│      └──────────────────────────────┘ (点击断开)  │
└──────────────────────────────────────────────────┘
```

## 问题

- 状态定义不符合用户实际需求
- 用户希望：点击可以同时启动服务、连接、开始录音
- 需要简化为更少的交互步骤
